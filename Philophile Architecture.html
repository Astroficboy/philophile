Philophile architecture

A single Node/Express process serves a vanilla-JS + D3 single-page app, merges curated data with the Stanford Encyclopedia index into one knowledge graph, and talks to a local Ollama model for tutoring. Nothing leaves your machine except fetches to plato.stanford.edu.

Three request paths

How the main features move through the layers above.

Era heat map

#/philosopher/kant/era-map → GET /api/philosophers/kant/era-map
  1. knowledge.eraMap() sets a window from 40 years before birth to 10 after death.
  2. Scores every philosopher, topic and event in the window (see the colour rules below).
  3. heatmap.js draws the tiles or the time map with D3.
  4. Clicking a topic opens #/topic/:id?with=kant. Clicking a philosopher opens their profile with ?from=kant and a connection banner.

Ask the tutor

POST /api/ai/ask → tutor.ask → ollama.chatStream
  1. tutor.js collects curated facts from knowledge.js.
  2. Loads the SEP entry through sep.js (cache first) and keeps the sections that best match the question.
  3. Sends the system prompt, context and chat history to Ollama with streaming on.
  4. Tokens flow back as chunked text; ai.js renders Markdown as they arrive.

Import every SEP philosopher

npm run sync, or POST /api/sep/sync from Settings
  1. sep-sync.js reads contents.html and keeps labels shaped like names.
  2. Fetches each candidate entry (400 ms apart) and parses dates from the preamble.
  3. Counts how often each entry names earlier philosophers; these become inferred influences.
  4. Writes sep-index.json, then knowledge.reload() merges it with the curated set.

How the era map assigns colour

Computed in knowledge.js for each item around the chosen philosopher.

Red · influenceDirect influences from any century get a heat of 0.45, 0.72 or 1 by weight. Influences of influences inside the window get 0.22. A topic's heat combines its rank in the philosopher's own topics with the share of influences that carried it.
Blue · same eraActive during the window with no recorded influence. Capped at 36 philosophers, curated ones and those closest in time first.
Violet · influencedLater thinkers inside the window who list this philosopher as an influence.
Amber · world eventEvents from the 97-entry dataset that fall inside the window. Shown for context, not clickable.
